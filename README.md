This folder consists of four components:

---

## 1. `process_codes/`
This directory contains the Python scripts used for data processing and analysis:

- **`merge_top5%.py`** – constructs the research sample  
- **`analysis_npc.py`** – computes the distribution of `new_phrase_comb`  
- **`analysis_DI.py`** – derives the DI thresholds  
- **`Cumulative_proportion.py`** – calculates cumulative proportions of research samples across the four fields for each publication year within the defined time window

---

## 2. `results/`
This folder stores the baseline data for the research samples, constructed from the OpenAlex dataset.

---

## 3. `stata_code/`
This directory contains the Stata scripts used to estimate the models and generate the corresponding `.docx` regression output tables.

---

## 4. `data/`
This folder includes the research samples and results used in the manuscript.
